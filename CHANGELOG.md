# Changelog

All notable changes to RandomItemChallenge will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-01-XX

### Added
- Initial release of RandomItemChallenge
- Periodic random item distribution to all players
- Custom item list with 80+ curated items including Minecraft 1.21 items
- Alternative mode to use ALL Minecraft items
- Comprehensive blacklist system to exclude items
- Configurable drop interval
- Multiple delivery methods (INVENTORY, DROP, HOTBAR)
- Random quantity support with min/max settings
- Enchantment system with configurable chance and levels
- Treasure enchantment toggle
- Sound and particle effects on item receive
- Action bar notifications
- Title display on challenge start
- Countdown timer in action bar
- World whitelist filtering
- Game mode filtering (survival/adventure only)
- Permission-based bypass system
- Hot-reload support
- Complete admin commands
  - `/ric start` - Start the challenge
  - `/ric stop` - Stop the challenge
  - `/ric toggle` - Toggle on/off
  - `/ric skip` - Skip to next drop
  - `/ric interval` - Set/view interval
  - `/ric status` - View current status
  - `/ric reload` - Reload configuration
- Full 1.21+ item support including:
  - Mace
  - Wind Charge
  - Breeze Rod
  - Heavy Core
  - Copper variants (Bulb, Door, Trapdoor, Grate)
  - Cherry and Bamboo wood items
  - Armor Trim materials
  - And more!
